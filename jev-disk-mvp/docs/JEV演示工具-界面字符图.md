## 图 5 · 动效时间轴（点「开始扫描」之后发生什么）

```
   0.0s  点击 [开始扫描]
          │
   0.2s   ├── 第一批 15 行从顶部插入，新行底色闪绿后褪去
          │   同时三个数字滚动：已分析 0→612 / 可回收 0→8.42GB / 平均把握 0→0.41
          │
 每115ms  ├── 再插 15 行  ……  600 行约 4.6 秒流完
          │
   4.6s   ├── 最后一批落定，按钮变成 [重新扫描]
          │
   4.8s   └── 定格

   要点：不是一行一行插，是「一批 15 行同时落」—— 这样才有瀑布感
```
