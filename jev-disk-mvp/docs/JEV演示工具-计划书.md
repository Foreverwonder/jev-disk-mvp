# JEV 磁盘体检 · 演示工具计划书

> 目标：**做一点能吹牛、能截图、能录屏的东西**。不是真清理工具。
> 日期：2026-09-20 · 依据：今天 MVP 实验的 30 个真实样本

---

## 0. 先正面回答你那个问题：JEV 能返回「理由」吗？

**不能给散文式理由。** 它不生成文字 —— 你不给它选项，它什么都说不出来。

但它能给**三样东西，拼起来就是理由**：

| 它能给的 | 长什么样 | 在 UI 里怎么变成"理由" |
|---|---|---|
| **类别概率分布** | 认为这是缓存 80% / 安装包 12% / 看不懂 8% | 一条堆叠概率条 |
| **可再生成程度分布** | 重新跑就会再生 91% / 要重新下载 7% | 另一条概率条 |
| **置信度** | 0.28（它自己只有 28% 把握） | 一个色块 + 警示图标 |

**这就是关键点**，也是最能吹的地方：

> 别的 AI 会给你一段听起来很有道理的解释。
> JEV 不给解释，它把「我有多大把握」直接摆给你看。

**诚实提醒**：如果你看到"理由：路径含 logs 所以是缓存"这种话，那是我（规则）加的，不是 JEV 说的。
计划里我把这两层**在 UI 上分开显示**，并明确标注来源 —— 这反而是加分项，显得你真懂。

## 1. 一句话说清楚能做出来什么

**一个本机小工具：你选一个目录 → JEV 逐个打分 → 出来一张可以直接发小红书的「AI 体检报告」。**

从点"开始"到出结果，30 个对象大约 **1~2 秒**（今天实测：2 次请求 1.1s / 1.5s）。

---

## 2. 三条硬前提（先说清楚，免得后面尴尬）

1. **全程只读。** 不删除、不移动、不改名任何文件。它只是"看"。
2. **UI 上的"删除"按钮是演示态。** 点了只会画个动画说"演示模式，没有真的删"。
   > ⚠️ **实际未实现** —— 2026-09-20 对抗性审查发现：MVP 界面里**根本没有删除按钮**，这条一直是空头承诺。见审查报告 R1。
   这样录屏时有那个"爽感"，但你不担风险。
3. **一键脱敏导出。** 截图里会暴露 `C:\Users\<user>` 和你的项目名 —— 发公开平台前必须能一键替换成 `C:\Users\***`。**这个功能是刚需**，我建议默认开启。

## 3. 技术方案（零依赖，一条命令跑起来）

```
jev-scan.exe / python jev_ui.py
        │
        ├── 扫描层（Python 标准库）
        │     os.walk 取元数据：名称 / 路径 / 体积 / 文件数 / mtime / 扩展名分布 / 最大样本名
        │     可选「内容指纹」：文本文件读前 30 行、二进制读魔数 → 给 JEV 更多线索
        │
        ├── 判断层（JEV）
        │     每批 15 个候选，每候选 3~4 个问题 → 一次请求并行
        │     返回：类别分布 / 可再生成分布 / 置信度
        │
        └── 展示层（单页 HTML，本地 http://127.0.0.1:8xxx）
              概率条 · 置信度色带 · 排序表 · 长图导出
```

**为什么不用 npm / 前端框架**：一条 `python jev_ui.py` 就能跑，不装任何东西。
你录屏的时候不用先等 `npm install`，观感也干净。

### 4.2 三个视觉锚点（决定"看起来专业"）

1. **顶部一个大数字**：可回收体积（`5.05 GB`）—— 截图的视觉中心
2. **概率条**：让"AI 在权衡"这件事可视化，区别于"AI 拍脑袋给个结论"
3. **置信度色带**：绿/黄/红三档，一眼看出哪些是它瞎猜的

### 4.3 录屏动线（20 秒版）

```

⑤ 切到"三档分诊"视图           （4s）
```

## 5. 十个候选方向（挑一个，或者组合）

按「炫酷程度」「工作量」「适合发哪儿」三个维度排的。

### 🥇 A. 网页体检报告（+长图导出）
- **做什么**：本地网页，选目录 → 打分 → 出报告 → 一键出小红书长图
- **炫点**：成品感最强，一张图讲完一个故事
- **工作量**：中
- **适合**：小红书（长图）＋ 朋友圈
- **评价**：**最稳的主力**，建议必做

### 🥇 D. 置信度三档分诊视图
- **做什么**：按 JEV 自报把握程度把对象切成三堆（可以信 / 复核 / 必须人看）
- **炫点**：**这是全篇最有品味的展示**。别人晒 AI 都在晒"它多准"，你晒"它知道自己不准"
- **工作量**：小（就在 A 里加一个视图）
- **适合**：小红书配文"我让 AI 承认自己看不懂"
- **评价**：**建议必做**，话题性最强

### 🥇 J. JEV vs 普通 LLM 对照跑
- **做什么**：同一个目录，JEV 判一遍、某个 LLM 判一遍，对照**耗时 / 成本 / 一致性**
- **炫点**：**吹牛含金量最高**。今天实测 JEV 服务端 63~146ms；LLM 同任务要秒级。
  厂商宣称 193.6x 更快 / 444.6x 更便宜 —— **你可以现场跑出你自己的数字**
- **工作量**：小（多调一个模型而已）
- **适合**：小红书技术向 + 朋友圈
- **评价**：**建议必做**。而且成本对比那张图，天生适合做封面

### 🥈 B. 终端流式 TUI（录屏神器）
- **做什么**：`jev scan .` 在终端里逐行刷结果，带彩色概率条
- **炫点**：录屏观感最"黑客"，有流速感
- **工作量**：小
- **适合**：B站 / 视频号 / 长录屏
- **评价**：想录视频就加这个，30 分钟能做完

### 🥈 C. 「JEV vs 我的规则」分歧对照
- **做什么**：左边 JEV 的判断，右边纯规则（路径含 cache 等）的判断，**高亮分歧点**
- **炫点**：分歧就是内容。"模型和规则意见不一样的时候，谁对？"
- **工作量**：小
- **适合**：小红书（配文有强观点）
- **评价**：很有料，但需要你有自己的观点立场

### 🥈 H. 「它也认怂」诚实版
- **做什么**：故意往扫描目录里混入几个它一定判不准的（比如 `.git/objects` 哈希名文件），
  然后展示它 confidence 掉到 0.00 的样子
- **炫点**：**反套路**。所有人都在晒 AI 多强，你晒 AI 说"我不知道"
- **工作量**：几乎为零（我们今天已经有真实案例了）
- **适合**：小红书，差异化最强
- **评价**：我私心最推荐这个角度。**你手上已经有一手素材**

### 🥉 E. 多目录横向对比
- **做什么**：一次扫 3 个目录（桌面 / 下载 / 文档），比谁最该清
- **炫点**：适合做"三方对比"图
- **工作量**：小
- **适合**：小红书
- **评价**：不错但略平

### 🥉 F. 实时扫描动画
- **做什么**：假装"扫描中"的雷达动画，其实是在等 API 返回
- **炫点**：视觉张力
- **工作量**：小（纯前端动画）
- **适合**：录屏
- **评价**：锦上添花，别当主菜

### 🥉 G. 单文件拖拽版
- **做什么**：拖一个文件进去，问"这能不能删"
- **炫点**：极简，最好懂
- **工作量**：极小（半小时）
- **适合**：朋友圈小视频
- **评价**：可以当 A 的副产物顺手做

### ⚪ I. 九宫格素材包
- **做什么**：跑完自动出 9 张卡片，直接发九宫格
- **炫点**：省事
- **工作量**：小
- **适合**：朋友圈
- **评价**：打包功能，不是独立方案

## 6. 我推荐的组合

**主力用 A，里面嵌 D，再单独跑 J。**

理由：
- **A** 给你成品感（能截图、能出长图）
- **D** 给你观点（"它知道自己不知道"——这是你区别于其他晒 AI 的人的地方）
- **J** 给你硬数字（更快、更便宜，可验证，不是喊口号）

三个加起来就是完整一条：**"我做了个工具，它很快很便宜，而且它敢说我不知道。"**

**随手再加两样**：B（想录视频就做）+ H（你今天已经有一手素材，白送）。

## 7. 诚实性 & 风险清单

| 风险 | 处理 |
|---|---|
| 被误认为真删了东西 | 报告页脚明确写"全程只读，未修改任何文件"；删除按钮做演示态 |
| 截图暴露用户名/项目名 | 默认开启脱敏（`C:\Users\<user>` → `C:\Users\***`） |
| 把 JEV 的误判当结论发出去 | **主动展示误判**（`.git` 那 6 个），反而显专业 |
| 观众以为"分数=真理" | 每个分数旁边都带置信度色块，不让分数单独出现 |
| 隐私文件被扫进截图 | 建议只扫桌面/下载这类"展示安全"的目录，别扫文档和聊天记录 |

---

## 8. 需要你拍板的三件事

1. **选哪几个方向？**（我推荐 A + D + J）
2. **演示扫哪个目录？** 建议 `桌面` 或 `下载` —— 素材杂、有对比、且不涉及隐私
    （**别扫 `文档`**，里面是你 QQ 聊天记录和游戏数据）
3. **要不要"内容指纹"？** 即让工具读文本文件的前 30 行喂给 JEV，判断会更实在，
   但扫描会从 1 秒变成十几秒。**演示用建议不要**，快更重要。

拍板之后我就开工。按我的估计，**A + D + J 三件一起，一次做完**。
